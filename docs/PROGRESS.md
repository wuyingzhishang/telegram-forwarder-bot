## 当前暂停点

用户最新需求是调整“消息转发”入口：

1. 普通消息转发侧不显示或询问来源频道/群组 ID。
2. 用户转发消息后，选择使用机器人账号还是已登录的个人 Telegram 账号发布到目标频道。
3. “来源 ID”只保留给确实需要自动监听来源的新消息的实时规则；普通手动转发不能进入来源 ID 向导。

普通直接转发和发布账号选择已经完成。当前部署环境的 `.env` 尚未配置 `API_ID`、`API_HASH` 或启用 `USER_SESSION_ENABLED=1`，因此个人账号按钮会提示先完成登录并启动 user-session 服务；机器人账号转发不受影响。

## 继续开发建议

- 如需启用个人账号发布，在 `.env` 配置 Telegram `API_ID`、`API_HASH`、`USER_SESSION_ENABLED=1`，完成二维码登录后启动 `user-session` profile。
- 保持实时规则向导独立，来源 ID 仅用于实时监听配置，不放入普通手动转发入口。
- 部署后可从 Bot 的“账号与登录”查看 user-session 是否在线及已连接账号 ID。
